组员请使用上级目录的「启动HAJIMI.bat」一键启动（自动配置环境 + 校园 GPU 全栈）。

本文件夹为开发者/高级入口：
  start_gpu_one_click.bat  — 英文别名，同 启动HAJIMI.bat
  check_deploy.bat         — 只检查环境/链路，不启动 GPU
  start_all.bat            — 本机 / gpu_api 全栈（需已开隧道）
  start_ui.bat             — 仅 B 端 UI
  start_mock.bat           — Mock 演示
  test_click_fixed.bat     — 固定坐标点击 Tier1（直接 clicker）
  test_click_http.bat      — 固定坐标点击 Tier2（8011 HTTP）
停止服务：上级目录 stop_all.bat
