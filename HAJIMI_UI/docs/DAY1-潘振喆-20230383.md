## 一、DAY1 目标（对照六天冲刺）

| 路线阶段 | 天数 | DAY1 对应里程碑 |

| **环境 + 骨架** | 第 1 天 | FastAPI Mock 就位；PyQt5 毛玻璃窗口；截图函数；OmniParser 环境验证 |

## 四、DAY1 验收标准

### 4.1 必须通过

1. A 端：`curl http://127.0.0.1:8010/api/demo/health` → `{ "status": "ok" }`
2. B 端：`python main.py` 可启动，窗口可见（Web 或早期 Native）
3. B 端：截图函数可返回非空 PNG bytes
4. OmniParser 目录存在，权重路径可解析（或文档说明外置 `E:\Tools\OmniParser`）

### 4.2 DAY1 不要求

- 真实 LLM / OmniParser 检测（DAY2+）
- B↔A 完整 process 闭环（DAY2）
- C 端与 B GUI 联调（DAY3 计划）
- Native UI v2 全量（DAY2–4 迭代）
