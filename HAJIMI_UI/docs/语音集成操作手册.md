# HAJIMI 语音集成操作手册（B ↔ C）

## 架构

B 端 PyQt5 与 C 端 `client/` **同进程**：`VoiceIntegrationController.bind_to(BCIntegrationSignals)`。

```
点击 mic → asr_start → C ASR → asr_result → 填入输入框（不自动发送）
步骤切换 → tts_enqueue → C TTS → tts_status → 扬声器图标 / stage_hint
任务结束 → audit_submit → C AuditAgent → POST /api/demo/report
```

## 一键验收顺序

在仓库根目录（`Fuzzy-Visual-Assisted-Question-Answering-System`）：

```powershell
# 1. 安装 C 依赖
pip install -r client/requirements.txt

# 2. 确认 Vosk 模型（需含 am/ 子目录）
# 路径: models/vosk-model-small-cn-0.22/

# 3. C 模块健康（非交互）
python -c "import sys; sys.path.insert(0,'.'); from client.integration.controller import VoiceIntegrationController; c=VoiceIntegrationController(); c.start(); h=c.health_check(); print(h.overall, h.asr_available, h.tts_available); c.shutdown()"

# 4. B↔C 信号
cd HAJIMI_UI
$env:HAJIMI_C_ENABLED="1"
python scripts/verify_bc_signals.py

# 5. 启动 B 端（语音模块首次点麦克风时加载，启动更快）
python main.py
```

## 懒加载语音

- B 端**启动时不加载** C 语音模块，减少卡顿
- **首次点击麦克风**时加载（约 1～几秒），之后正常
- 设置页仍显示「语音模块将在首次使用时加载」

## Google ASR 与代理

- Google 需本机 Python 能访问 Google（国内通常需 Clash/VPN）
- **系统设置 → 模型设置** 末尾：
  - 勾选「启用 HTTP(S) 代理」（**默认关闭**，不影响启动本地的 A/隧道）
  - HTTP 代理如 `http://127.0.0.1:7890`（端口按 Clash 实际值）
  - 仅作用于 **B 端进程**；本机 `127.0.0.1` 已加入 `NO_PROXY`
- 通过 `启动本地.bat` / `联调启动.bat` 启动时，B 窗口会自动读取已保存的代理设置
- Google 网络失败时会**自动降级 Vosk**（若已安装模型）

设置 → **语音设置**：

- 启用 ASR/TTS；选择 **ASR 引擎**（`vosk` 离线 / `google` 在线，google 需可访问 Google）
- **麦克风设备**：选具体输入设备或「系统默认」
- **Vosk 模型路径**：默认 small；可换 `models/vosk-model-cn-0.22` 大模型
- **开说等待 / 静音结束**：调整录音行为（秒）
- 保存后底部 **C 端健康** 行应显示 `ASR=可用` 及当前引擎

## 麦克风交互

| 操作 | 行为 |
|------|------|
| 点击 mic | 开始录音，按钮高亮 |
| 再次点击 | 立即结束并转写 |
| 开说前 10s 无语音 | 自动结束，提示「未识别到语音内容」 |
| 说完后静音 5s | 自动结束并转写 |
| 转写结果 | **仅填入输入框**，需手动点发送 |

环境变量（可选）：

- `HAJIMI_ASR_SILENCE_SEC=5`
- `HAJIMI_ASR_START_TIMEOUT_SEC=10`
- `HAJIMI_C_ENABLED=1`（默认开启）

## 排错

| 现象 | 处理 |
|------|------|
| mic 灰色 | 设置开 ASR；若 C 未加载，首次点 mic 会触发加载 |
| `No module named client.integration` | 旧版在 `HAJIMI_UI/client/` 留下 shadow 目录；删除该文件夹并重启，或更新到已修复版本 |
| Google 10054 | 模型设置启用代理 + Clash 运行；或 ASR 改 vosk；失败会自动试 Vosk |
| 录音失败 PyAudio | 在**启动 B 端的同一 Python** 执行：`pip install pyaudio` |
| 部分 C 端服务降级 | A 端 `:8010` 未开时的正常提示；**语音 ASR/TTS 仍可用**，可忽略或启动 A 端 |
| 无 TTS 声音 | Windows 语音包 / pyttsx3；设置开 TTS |
| audit 不上报 | A-end `:8010` 运行；`server/.env` 中 Demo Key 与 B 一致 |
