Version 6.0
===========

Release Date: 2023-08-10
Download: https://royaltsx-v6.royalapps.com/updates/royaltsx_6.0.0.1000.dmg

Improvements:
* Password Analyzer (in the "View" menu)
* Connection State monitoring for selected connections in navigation panel (can be disabled in Settings - Behavior - Monitor state of connections in navigation panel)
* Support for searching in the properties dialog
* New VNC plugin: RoyalVNC
* Secure Gateway Cipher Configuration
* New replacement token picker
* New Dynamic Folder export format (XML)
* Custom icon support in KeePass documents
* Support for new $Clipboard$ replacement token
* Improved UI of disconnected connections
* Disconnected connection tabs now have alternate context menu items for disconnecting/reconnecting all disconnected (by holding the option key)
* The Overview/Dashboard tab now has a context menu
* A new app setting to focus the connection on the "Behavior" page for double-clicking an active connection
* The 'Arc' browser now works with the Royal Passwords extension
* Added support for TeamViewer connections in Remote Desktop Manager import
* Support for overriding properties in ad hoc connections using the ?property_name=property_value syntax
* Added support for opening/closing existing connections using the rtsx:// URI scheme's "using=id/name" and "action=connect/disconnect" syntax
* Properly handle properties from parent folder in RoyalJSON when 'Path' property is used
* Many performance and stability improvements
* Many UI tweaks
