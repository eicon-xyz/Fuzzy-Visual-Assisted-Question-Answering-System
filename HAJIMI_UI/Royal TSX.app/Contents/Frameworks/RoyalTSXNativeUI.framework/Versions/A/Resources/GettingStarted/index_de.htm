Erste Schritte mit Royal TSX

Schritt 1:  Plugins installieren

Royal TSX ist eine Plugin-basierte Anwendung. Das heißt, bevor Sie sich tatsächlich mit einem entfernten Computer verbinden können, müssen Sie das Plugin installieren, das für die jeweilige Verbindungstype erforderlich ist.

Um Plugins zu installieren, öffnen Sie das "Royal TSX" Menü und wählen Sie "Einstellungen". Navigieren Sie dann zu der Sektion "Plugins". Sie können auch einfach hier klicken.

Auf der Plugins-Seite können Sie Plugins für Verbindungstypen installieren, deinstallieren und aktualisieren.

Schritt 2:  Ein Dokument erstellen

Wenn Sie Royal TSX zum ersten Mal starten, werden Sie feststellen, dass automatisch ein "Anwendungs"-Dokument für Sie erstellt wurde. Dieses Dokument hat einige besondere Eigenschaften:

  • Sie können das Anwendungs-Dokument mit einem Passwort schützen. Danach werden Sie bei jedem Start von Royal TSX aufgefordert, dieses Passwort einzugeben.
  • Sie können Ordner, Anmeldeinformationen, Aufgaben und Verbindungsvorlagen erstellen und Standardeinstellungen bearbeiten.
  • Sie können es nicht schließen oder löschen.
  • Sie können keine Verbindungen erstellen.

Um tatsächlich Verbindungen zu erstellen, müssen Sie ein neues Dokument erstellen. Wählen Sie dazu den Menüpunkt "Neues Dokument" im "Ablage"-Menü. Sie werden feststellen, dass dem Navigations-Panel auf der linken Seite des Hauptfensters neue Elemente hinzugefügt wurden.

Dokumente können jeden von Royal TSX unterstützten Objekttyp enthalten. Sie können beliebig viele Dokumente erstellen, aber immer nur ein Anwendungs-Dokument.

Schritt 3:  Erste Verbindung hinzufügen

Nachdem Sie nun ein oder mehrere Plugins installiert und ein neues Dokument erstellt haben, können Sie damit beginnen, Verbindungen zu erstellen und Royal TSX zu verwenden. Um eine neue Verbindung zu erstellen, wählen Sie den Ordner "Verbindungen", der automatisch erstellt wurde, und klicken Sie dann auf den kleinen "Plus-Button" in der unteren linken Ecke des Navigations-Panels im Hauptfenster. Wählen Sie hier den Verbindungstyp aus, für den Sie eine Verbindung erstellen möchten.

Nachdem Sie auf den Menüpunkt für den Verbindungstyp, den Sie hinzufügen möchten geklickt haben, gelangen Sie zum "Verbindungseinstellungs-Dialog". Hier können Sie alle für eine bestimmte Verbindung verfügbaren Einstellungen bearbeiten. Der Dialog bietet auch einige generische Einstellungen, die bei allen Verbindungstypen geändert werden können, wie z. B. "Notizen" und "Benutzerdefinierte Eigenschaften".

Nachdem Sie Ihr erstes Verbindungsobjekt erstellt haben, können Sie sich auf den entfernten Computer verbinden, indem Sie die neu hinzugefügte Verbindung im Navigations-Panel doppelklicken.

Tipp: Denken Sie daran, dass Sie Verbindungsobjekte nur erstellen oder bearbeiten können, wenn Sie ein passendes Plugin für den jeweiligen Verbindungstyp installiert haben.

 

Jetzt, da Sie die Grundlagen von Royal TSX kennen, genießen Sie Remote-Verbindungen wie nie zuvor unter macOS!

Vielen Dank, dass Sie Royal TSX verwenden!
