 /api/audit/report 
 批量审计上报 
 X-Demo-Key

 字段 类型 必填 说明

 batch[].query string ✅ 脱敏后用户提问 
 batch[].intent_category string ✅ 九大意图域 
 batch[].route string ✅ L2 / L3 
 batch[].result string ✅ success / fail / cancel / redirect / rejected 
 batch[].duration_ms int ✅ 耗时(毫秒)

 第三部分：B-C 进程内信号 (Qt Signals — 同一 PyQt5 进程) 
 B 端与 C 端通过 PyQt5 信号/槽通信。C 端 bc_adapter.py 提供接入。 
 → asr_start / asr_stop ASR 录音控制 (B→C) 
 mic_button.pressed → C 开始录音；released → 停止录音并转写。 
 ← asr_result ASR 转写结果 (C→B) 
 参数: (transcript: string, confidence: float, engine: string, error: string|null)。 
 → tts_enqueue TTS 播报触发 (B→C) 
 参数: (text: string, priority: int=0, interrupt_current: bool=false)。步骤切换时触发。 
 ← tts_status TTS 状态回传 (C→B) 
 参数: (status: playing|completed|error, text: string, queue_depth: int)。 
 ⇄ voice_settings 语音设置同步 (B↔C 共享状态) 
 dict: { tts_enabled, tts_speed(0.5~1.5), tts_engine, asr_enabled, asr_engine, asr_language }。 
 → audit_submit 审计数据提交 (B→C) 
 任务结束 emit AuditRecord → C 审计代理脱敏后入本地 SQLite 队列。 
 ← audit_status 审计上报状态 (C→B) 
 参数: (status: success|failed|queued, batch_size: int, queue_depth: int, error: string|null)。 
 ← config_updated 配置变更通知 (C→B) 
 参数: (config_dict)。C 端 poller 检测到变更后通知 B 热加载。 
 → health_check 健康检测 (B→C 方法调用) 
 返回 HealthStatus: { asr_available, tts_available, audit_db_ok, server_reachable, queue_depth, overall }。

 V2.2 自动操作动作类型 (execute 响应 action 字段) 
 action 说明 执行 关键参数 
 click 单击 pyautogui.click bbox_center 
 double_click 双击 pyautogui.doubleClick bbox_center 
 type 输入文本 pyautogui.write params (内容) 
 hotkey 组合键 pyautogui.hotkey params ("ctrl+c") 
 drag 拖拽 pyautogui.drag from→to bbox 
 scroll 滚轮 pyautogui.scroll params 
 执行前经风险评分(1-5)+红线拦截+信任级别三重审核。高风险操作(≥4)需用户确认。
