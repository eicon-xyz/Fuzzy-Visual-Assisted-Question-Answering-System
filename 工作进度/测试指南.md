| `No module named 'fastapi'` | `pip install fastapi uvicorn` |
| `No module named 'cv2'` | `pip install opencv-python-headless` |

| Web 面板图表不显示 | `cd web-admin && npm install` |
| 端口被占用 | 见下方 |

### 端口冲突处理

```bash
# 查端口
cmd //c "netstat -ano | findstr :8000 | findstr LISTENING"

# 杀进程（替换 PID）
cmd //c "taskkill /F /PID <PID>"

# 一键杀三个端口
cmd //c "for /f \"tokens=5\" %a in ('netstat -ano ^| findstr /R \":8000 :8010 :8002\" ^| findstr LISTENING') do taskkill /F /PID %a"
for /f "tokens=5" %a in ('netstat -ano ^| findstr /R ":8000 :8010 :8020" ^| findstr LISTENING') do taskkill /F /PID %a
```
