## 十、常见问题

| 问题 | 解决 |
|------|------|
| 端口被占用 [WinError 10048] | `cmd //c "for /f \"tokens=5\" %a in ('netstat -ano ^| findstr :8010 ^| findstr LISTENING') do taskkill /F /PID %a"` |
| A 端启动慢 (5-8s) | 正常 — 初始化 7 个 DB 表 |
| A 端返回 500 | 检查 `pip install sqlalchemy psutil` |
| Web 面板空白 | `cd web-admin && npm install` |
| 测试显示 A 端离线 | 先启动 A 端再跑测试 |
| 数据库在哪 | `new_JIMI/HAJIMI_UI/data/hajimi.db`（首次启动自动创建） |
| 没有 LLM Key | 能启动，/execute 返回 Mock 降级 |

### 端口冲突完整处理

```bash
# 查端口
cmd //c "netstat -ano | findstr :8010 | findstr LISTENING"
# → TCP  127.0.0.1:8010  ...  LISTENING  <PID>

# 杀进程
cmd //c "taskkill /F /PID <PID>"

# 一键杀所有项目端口
cmd //c "for /f \"tokens=5\" %a in ('netstat -ano ^| findstr /R \":8010 :5173\" ^| findstr LISTENING') do taskkill /F /PID %a"
```
